# SE122 Image Sharing Social Media

## Project Structure

- **Backend**: `backend/v1_nestjs` - NestJS API Service.
- **Frontend**: `frontend/cross-platform` - Expo (React Native) App.

## Features
- **Memories**: Map-based photos and voice notes.
- **Social**: Custom social graph, posts, likes, comments.
- **Media**: Cloudinary integration.

## Quick Start

### Backend
1. `cd backend/v1_nestjs`
2. `npm install`
3. `npx prisma generate`
4. `npm run start:dev`

### Frontend
1. `cd frontend/cross-platform`
2. `npm install`
3. `npx expo start`
